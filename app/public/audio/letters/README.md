# Recorded letter audio

One WAV file per letter, named by its **uppercase canonical letter**:

```
public/audio/letters/A.wav
public/audio/letters/B.wav
...
public/audio/letters/Z.wav
```

That's it — no code changes, no manifest to update. `engine/audio.ts`
tries `/audio/letters/<LETTER>.wav` first for every letter it speaks;
if the file exists, it plays that. If it 404s, it silently falls back
to the browser's built-in speech synthesis. You can add letters
incrementally, in any order — a half-finished set works fine, every
letter just independently uses whichever source is available for it.

## What's here

Just the **letter name** spoken clearly and warmly, e.g. "Ay" for A,
"Bee" for B — the same thing `speak()` is currently asked to say. No
need to record the lowercase/uppercase distinction separately; the
audio is about the letter's *name*, not its visual case, so `A.wav`
covers both "A" and "a" prompts.

## How this set was generated

All 26 clips here were generated by `assets/generate-audio.mjs` using
the Gemini API's text-to-speech model (`gemini-3.8-flash-tts`, voice
`Sulafat` — described by Google as "Warm"), styled with a warm, kind,
gently-enthusiastic delivery instruction. See that script's header
comment and `docs/07-architecture.md#audio-strategy` for details.

To regenerate (e.g. after tuning the voice/style, or if a clip sounds
off):

```bash
cd assets
npm install                 # once
cp .env.example .env        # once, then paste in a key from https://aistudio.google.com/apikey
node generate-audio.mjs --only=letters --force
```

The script reads the letter list straight out of
`app/src/engine/letterNameMatch.ts`, so it can't drift out of sync with
what the app actually says.

## Format notes

- WAV (24kHz mono 16-bit PCM) is what the TTS model returns natively —
  no transcoding step, and every target browser plays it fine for a
  short clip like this. `engine/audio.ts` requests `.wav`; if you drop
  in files from a different source, convert to WAV first (or ask for
  the extension to be made configurable).
- Keep clips normalized in volume relative to each other — a loud "A"
  next to a quiet "B" is jarring letter-to-letter. The shared voice/
  style instruction in `generate-audio.mjs` keeps the generated set
  consistent by construction; if you hand-replace individual clips from
  another source, match levels by ear.
