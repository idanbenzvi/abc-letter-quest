# Recorded word audio

One WAV file per word, named by its **id** (not its display text):

```
public/audio/words/apple.wav
public/audio/words/firetruck.wav   # WordEntry.id 'firetruck' -> displayed as "Fire Truck"
public/audio/words/xray.wav        # id 'xray' -> displayed as "X-ray"
...
```

`engine/audio.ts` normalizes whatever text it's asked to speak (lowercases
it, strips punctuation/spaces) and looks it up against every word's `id`
in `src/data/words.ts`, `src/data/flashcards.ts`, and
`src/data/cvcWords.ts` to find the right file. If it 404s, it silently
falls back to the browser's built-in speech synthesis — same "missing
file = silent fallback" shape as `public/audio/letters/`. You can add
words incrementally, in any order.

This covers every word the game ever speaks: flash-card words
(`FlashCardSky`), the word shown on `LetterLearning`, the picture-spot
challenge's word, and the CVC blending round's letters *and* the
blended whole word (e.g. tapping C-A-T speaks "Cat" — reusing the same
clip as the `cat` flashcard, since it's the same sound either way).

## How this set was generated

All clips here were generated by `assets/generate-audio.mjs` using the
Gemini API's text-to-speech model (`gemini-3.8-flash-tts`, voice
`Sulafat` — described by Google as "Warm"), styled with a warm, kind,
gently-enthusiastic delivery instruction — the same voice used for
`public/audio/letters/`, so the whole game sounds like one consistent
speaker. See that script's header comment and
`docs/07-architecture.md#audio-strategy` for details.

To regenerate (e.g. after adding a new word to `words.ts`, or tuning
the voice/style):

```bash
cd assets
npm install                 # once
cp .env.example .env        # once, then paste in a key from https://aistudio.google.com/apikey
node generate-audio.mjs --only=words --force
```

The script reads the word list straight out of the app's own data
files (regex-extracted, not hand-copied), so it can't drift out of sync
with what the app actually shows — add a word to `words.ts` and rerun
without `--force` to generate just the new one.

## Format notes

Same as `public/audio/letters/README.md`: WAV, 24kHz mono 16-bit PCM,
what the TTS model returns natively.
